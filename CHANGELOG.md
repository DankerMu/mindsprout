# mindsprout

## 0.2.0

### Minor Changes

- 562e356: Add framework-independent account registration, sign-in, session resolution and sign-out with exact credential bounds and fixed thirty-day sessions. Session issuance atomically binds to the registered or verified credential so password reset invalidates existing sessions and prevents stale issuance. Interrupted registration fails internally while retaining the account and its replacement credential.
  
  Add administrator-only account listing and password reset. Reset returns a temporary password and atomically replaces the credential while ending all of the target's sessions, including the administrator's own sessions on self-reset. Other accounts remain unchanged; non-admin actors are refused before any port operation.
  
  Add Node crypto adapters for asynchronously salted scrypt password hashes with a fixed resource profile, canonical credential verification and timing-safe key comparison. Malformed hashes and verification failures refuse authentication; hashing failures propagate. Session tokens use 32 random bytes and temporary passwords use 12 random bytes, encoded as base64url.
  
  Add injected-client Postgres account and session repositories. First registration is serialized before admin assignment; exact duplicate usernames preserve existing credentials. Session tokens are stored as SHA-256 digests with strict supplied-clock expiry. Password reset and credential-bound issuance share a user-row lock, so reset either removes an issued session or refuses stale issuance while preserving other accounts.
  
  Add the account-to-map ACL and injected-client Postgres map store. Each operation uses transaction-local RLS identity; owner-scoped upserts preserve verbatim maps and isolate identical ids across users. Lists retain readable newer-version summaries while skipping null summary fields; only get rejects newer schema versions.
  
  Add GET `/api/auth/session`, returning only the current username and administrator flag or a generic unauthenticated response. Server composition lazily shares a five-connection Postgres pool, preserves opaque session cookies, and provides scoped HttpOnly cookie issuance and clearing with Secure in production. Unexpected failures return a generic internal error without logging credentials.
  
  Add POST `/api/auth/register` and `/api/auth/login`, returning only the username and administrator flag and setting the session cookie on success. Malformed JSON and non-string credential fields return `400 invalid-input` before account or session operations; exact-string bounds remain in the account core. Duplicate usernames return 409, invalid sign-in credentials return 401, and interrupted registration returns a generic 500 without a cookie or retry.
  
  Add POST `/api/auth/logout`, deleting the current session and clearing its cookie with an empty 204 response, including absent or unknown sessions. Register, login and logout share an application/json media-type guard that returns `415 unsupported-media-type` before reading the body or changing state. Logout failures return a generic 500 without clearing the cookie or logging secrets.
  
  Add authenticated GET `/api/maps` and `/api/maps/{id}` on the shared account Postgres pool. Lists preserve repository order; individual reads return a version-one map envelope, 404 for absent or other-user maps, or 409 with the stored unsupported version. Session denial precedes map access and dynamic parameters. Unexpected failures return a generic 500 without logging map content or credentials.
  
  Add authenticated PUT and DELETE `/api/maps/{id}` with the shared JSON media guard. PUT limits declared and streamed bodies to 1 MiB and validates the forest, version and path id before saving; invalid maps return 400 and oversized bodies return 413 without writing. DELETE is idempotent for absent or other-user maps. Both return empty 204 responses on success.
  
  Add GET `/api/admin/users` and POST `/api/admin/users/{id}/password-reset` through the shared account services. Only administrators can list public accounts in oldest-first order or reset credentials. Missing sessions return 401; reset requires JSON media type before authorization and rejects malformed or unknown target ids with 404. The temporary password appears only in the successful response body; no admin response changes cookies, including self-reset.
  
  Serialize development role bootstrap through a shared maintenance-database lock while keeping per-database migrations concurrent. Scratch database setup retains LOGIN credentials, role safety flags and application grants without racing updates to the cluster-wide role catalog.
  
  Add an HTTP MapRepository adapter with validated map envelopes, same-origin requests and a distinct session-ended error. Saves synchronously enter one ordered session queue; idle requests start synchronously and use keepalive for JSON bodies up to 60,000 UTF-8 bytes. Later reads and writes wait for earlier requests to settle, including failures; network and malformed-response failures remain visible errors. Queued unload saves remain best-effort. The browser provider shares one adapter per document and account binding across remounts and client-side navigation; rendering on the server issues no map request.
  
  Bind queued map requests to the invoking account using a non-secret exact-username binding cookie and header, while keeping the session credential HttpOnly. Login and registration set both scoped cookies; logout clears both. First-party requests always carry the binding header, with an empty value when the cookie is absent or empty. Credential-only legacy sessions fail closed before map access; same-account reauthentication establishes the binding and restores normal editing. The server rejects mismatched bindings before map access, preventing Alice's held or queued saves from entering Bob's store after same-document or new-tab account switches. Navigation opens a fresh adapter before exposing another account's ready state; same-account re-login preserves bound pending edits. Direct API calls without the optional header retain their existing behavior.
  
  Preserve pending editor changes when an HTTP save reports session expiry, with a persistent notice and a re-login link targeting a new tab and a return to the library. Other save failures remain visible and retry the complete map on the next edit or flush; successful saves leave notices until explicit dismissal. Current library and editor loads redirect expired sessions to login with the current pathname, while discarded loads cannot redirect.
  
  Add public `/login` and `/register` pages sharing a credentials form that posts exact usernames and passwords as JSON. Pending submissions disable the submit button; invalid input, incorrect credentials, taken usernames and request failures show inline errors without navigation. Successful authentication returns to a same-site `next` path or `/` when the target is absent or unsafe.
  
  Requests to protected pages without a `mindsprout_session` cookie redirect with 307 to same-origin `/login`, preserving the requested path and query in `next`. The proxy checks only cookie presence; session validity remains checked at the data. Sign-in, registration, API routes and reserved static/image assets bypass the proxy.
  
  Show the signed-in username and sign-out action on the home and editor pages, with administrator navigation visible only to the admin. Each menu mount loads its session once, including StrictMode replay. Successful sign-out returns to `/login`; request failures keep the menu visible with an inline error.
  
  Add an `/admin` page with the session menu, exact account usernames and creation times in API order, and an administrator badge. Refused users see a home link without account data; expired loads open a fresh login document returning to `/admin`. Other load failures show an error, and discarded loads cannot publish data or redirect.
  
  Each account row offers a confirmed password reset that ends all of that user's sessions. Pending resets and open password dialogs block further resets. The temporary password appears once in a selectable, read-only dialog and is discarded on close or reload. Expired resets clear account data and use the same fresh login document; other reset failures retain the list and show a generic error.
  
  Keep reset-test credentials out of failure artifacts and reporter errors with describe-scoped snapshot suppression and error redaction. Explicit reset screenshots mask the password input; unrelated tests retain their diagnostics.
- 46ba57c: Delete selected canvas subtrees with Delete or Backspace as one undo step. The primary root stays protected while selected descendants and floating roots remain deletable; selecting the primary root shows “主根不能删除”. Undo restores complete subtrees, their order and floating positions. Text editing, composition and modified keys retain their native behavior.
- 74fe7fb: Select canvas nodes with click, Shift+click, or an enclosing drag rectangle. Use Ctrl/Cmd+A to select visible nodes, Escape to clear selection, and arrow keys to navigate from the last-clicked primary node. Text focus and composition keep their native shortcuts; panning preserves selection. Selection is session-only and does not save or alter the map.
  
  Space panning preserves selection even when focus is outside the canvas and resets on window blur. Drag rectangles accept only the primary left mouse pointer; touch gestures remain available for panning.
- 1106400: Undo and redo map edits with Cmd/Ctrl+Z and Cmd/Ctrl+Shift+Z or the canvas buttons 撤销 and 重做. Button availability follows session history, which is cleared on reload without losing saved map content.
  
  Text editing and IME keep native keyboard behavior. A toolbar pointer gesture that starts while naming a node only finishes that editor; it does not also consume map history. Cancelling an unnamed creation preserves earlier edits and redo entries, and the next idle activation works normally.
- b76d32b: Drag selected top-most subtrees together, preserving their relative positions when detaching to the canvas and appending them in visual order when attaching to a node. Each accepted drop is one undo step. Primary-root, self and descendant refusals reset the entire group without changing history or saving the map. Native cancellation stops all previews and edge autopan; a fresh gesture remains available after map, layout or editing changes.
- d077e3f: Rename existing nodes by double-clicking or pressing F2 on the canvas. F2 edits only the last-clicked primary node and preserves a multi-selection. Enter saves, Escape discards, and leaving the input saves without moving focus away from its destination.
  
  Titles accept any length, including 200 characters, and nonempty text is saved verbatim. Blank or unchanged titles leave the existing title and history untouched. Input composition and native text shortcuts do not trigger canvas actions; IME confirmation marked by keyCode 229 keeps the title draft open even after composition ends. Hidden or deleted edit targets discard their drafts. Committed renames use the existing undo history and browser autosave.
- f1ccd22: Create nodes from a single canvas selection: Tab adds the last child; Enter inserts the next sibling, or a child on a primary or floating root. The new node is selected and its title input receives focus once visible. Collapsed parents expand for naming.
  
  Naming and creation form one history entry. Empty or whitespace-only titles and Escape discard the creation, restore the prior selection and re-collapse its parent. Provisional nodes are not saved; named nodes use browser autosave. Modified or repeated keys, text entry and IME confirmation do not create nodes. Undo buttons and keyboard shortcuts are not introduced by this change.
- cafad64: Rename maps from the library with an explicit title form, or permanently delete them after confirmation. Rename updates the title and last-updated time without changing the tree or creating an undo step. Successful renames move into the library's newest-first order; failed mutations retain the saved row and allow an explicit retry.
  
  Newer-version maps refuse rename with “此导图由更新版本创建”. Every listed map can be explicitly deleted, including newer or odd-version records, without reading or migrating its contents. Records without readable summary metadata remain hidden and cannot be deleted through the library.
- 5e3fdcc: Open a stored map at `/maps/<id>`: the editor shows the map title and the canvas, and saves pending edits when the page is hidden or left. An unknown id shows "找不到这张导图", a map from a newer version shows "此导图由更新版本创建", and an unreadable map shows "无法打开这张导图", each with a link back to the library. Opening a map never changes it.
- 3329da6: Browse saved maps on `/` with titles and last-updated times, newest first, and open a map from its list entry. An empty library offers 新建导图, which saves a map titled 新导图 with one root of the same name before opening its editor. Creation accepts only one pending attempt; a failed save keeps the library visible and permits an explicit retry. Loading and read failures have distinct states rather than appearing as an empty library.
  
  Leaving the library or switching its repository suppresses late create navigation and error UI without cancelling the save; a committed map remains available on the next visit.
- db4d0ef: Right-click a node to add a child or sibling, rename, delete, collapse or expand, or detach its subtree in place. Delete uses the selected set when the target is selected; other actions use only the target. Root restrictions protect the primary root, and undo restores each completed action. Menus support keyboard navigation and preserve selection when dismissed. Color and note actions are not included.
- 84f0593: Keep editing when browser storage cannot open by sharing one in-memory repository across library creation and editor navigation. The editor shows a persistent 未保存到浏览器 banner; fallback maps last only until the document is reloaded. Unavailable reads show the banner and an error rather than pretending the map does not exist.
  
  Show the current editor notice, including 保存失败 after a failed write, with explicit dismissal. Failed saves retain edited text; generic write failures do not switch repositories. Notices have no automatic dismissal timer, so a replacement message is not cleared by an older notice.
- a6b5de3: Drag one node onto another to append its subtree, or onto empty canvas to detach or reposition a floating subtree. Placement preserves the pointer's grab offset, and one undo restores the original tree and position. Self, descendant and primary-root drops snap back without saving or adding history. Editing, pan gestures and multiple selections do not move nodes; group drag is not supported.
