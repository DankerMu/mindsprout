Open a stored map at `/maps/<id>`: the editor shows the map title and the canvas, and saves pending edits when the page is hidden or left. An unknown id shows "找不到这张导图", a map from a newer version shows "此导图由更新版本创建", and an unreadable map shows "无法打开这张导图", each with a link back to the library. Opening a map never changes it.
