# Design: ci-gate-hardening

## Context

Merged state on `main` at 626cec3:

- **`check-naming.sh`.** Shared `check_path` (#54). Staged mode reads `git diff --cached --name-only --diff-filter=AR` line by line. Path mode strips a leading `"$repo_root/"` and checks everything else as given.
- **`pr-diff-guard.yml` (#44).** This is the live-label pattern: label triggers, a per-PR concurrency group, `gh api …/pulls/N --jq '.labels[].name'`, no `if:`, and logic in `scripts/check-diff-size.sh`.
- **`ci.yml` `lockfile-consistency`.** Still uses the payload-label `if:`. It is not in the `all-checks-passed` needs list; it is its own required check.
- **Branch protection (verified 2026-11-05 with `gh api repos/DankerMu/mindsprout/branches/main/protection`).** strict true; contexts `All checks passed`, `Lockfile–manifest consistency`, `PR diff size guard`; linear history true; force-push and deletions false; `enforce_admins` false; no required reviews. Rulesets: `[]`.
- **`application/` imports today.** Only `zustand/vanilla`, `d3-hierarchy` and `nanoid`, none of which is a banned framework.

## Decisions

- **D1 (#61) NUL-separated staged read.** Use `git diff --cached --name-only -z --diff-filter=AR` with `while IFS= read -r -d '' f`, which works in bash 3.2. It yields raw bytes, so newlines and non-ASCII names are judged as the real path. Rejected: `core.quotePath=false`, because it still quotes newlines.
- **D2 (#59) Outside-repo paths are out of scope for a commit guard.** In path mode an absolute path is resolved physically:
  - Take the deepest existing ancestor directory, resolve it with `cd` + `pwd -P`, and append the non-existent remainder verbatim.
  - Inside `"$repo_root/"` → judge the repo-relative path.
  - Outside → exit 0.

  If the absolute argument contains a `..` segment anywhere, the outside exit is skipped and the argument is checked as given (today's behaviour), before any resolution — `cd` drops `..` as text while the filesystem follows a symlinked ancestor, so no `..` may carry a path to an outside verdict.

  `repo_root` must be physical: `git rev-parse --show-toplevel` already is, and the non-git fallback becomes `pwd -P`. Without the physical resolution, a symlinked route into the repository would fail open. Relative paths are judged as given, as today. Decision 0008 records this.

- **D3 (#37) Two anchored `to.path` entries.** `^node_modules/(next|react|react-dom|drizzle-orm|postgres|@supabase)(/|$)` and `^node_modules/\.pnpm/[^/]+/node_modules/(next|react|react-dom|drizzle-orm|postgres|@supabase)(/|$)`, mirroring `domain-is-pure`. A single optional-group regex fails depcruise's safe-regex check.
- **D4 (#47) Load the config; jscpd.json carries the only runtime threshold.** The script becomes `jscpd --config jscpd.json src`, with no CLI `--threshold`. `constraints.yaml` stays canonical; a guardrail case asserts that the `jscpd.json` threshold equals `anti_drift.duplicate_code_threshold_percent`. Rejected: counting test files, which needs a weakening decision record and dilutes the gate.
- **D5 (#38) Explicit plugin.** `plugins: ['@stryker-mutator/vitest-runner']`, with a comment naming the pnpm isolated-layout failure. Rejected: hoisting via `.npmrc`, which changes the whole dependency layout.
- **D6 (#49) Own workflow, live labels, logic in a script.** `.github/workflows/lockfile-guard.yml` mirrors `pr-diff-guard.yml`. It is a separate workflow so that label events re-run one small job, not all of CI; and with no `needs:`, a failed label lookup cannot turn into a skipped required check. `scripts/check-lockfile-pairs.sh` mirrors `check-diff-size.sh`'s contract.
- **D7 (#40) Correct 0006 in place.** Use `git mv` to move it to `implemented/testing/` and narrow the wording. The decision itself is unchanged; the record and its mirror simply misstated its scope, so this is a mechanical correction and needs no new record.
- **D8 (#53) Document what the API returns.** Record classic branch protection, strict up-to-date, linear history, no force-push or deletion, and `enforce_admins: false` (admins can bypass). Decision 0001 and the `constraints.yaml` downgrade text record the decision as it was made and stay as they are. `constraints.yaml` `ci.required_status_checks` is already accurate.
