# MindSprout 产品需求文档（PRD）

> 版本 0.1 · 2026-11-05 · 状态：已对齐核心方向，细节随迭代更新

## 1. 定位

**一句话**：给"想法先行、结构后补"的人用的 AI 思维导图工具。用户给一颗种子，AI 负责长枝叶，用户负责修剪。

**名字含义**：mind + sprout（发芽）。强调导图是"长出来"的，不是一次性"生成"的。

## 2. 目标用户

v1 面向个人知识工作者，典型场景：

| 场景     | 用户动作         | 期望结果                           |
| -------- | ---------------- | ---------------------------------- |
| 学习笔记 | 输入课程主题     | 得到知识点骨架，逐节点深入         |
| 读书拆解 | 粘贴书摘或章节   | 自动提炼成结构                     |
| 头脑风暴 | 输入一个模糊想法 | AI 发散出多个方向，用户挑选再展开  |
| 方案提纲 | 输入目标         | 得到可编辑的提纲树，导出到文档工具 |

v1 不做团队协作，但账号和云端存储从第一天就有，为多端同步和后续协作留路。

## 3. 核心用户故事

1. 输入一个主题，几秒内流式长出一张三层左右的导图骨架。
2. 选中任意节点，让 AI 对它做四种动作：**展开**、**换个角度**、**精简**、**举例**。
3. 粘贴一篇文章或会议纪要，自动提炼成导图。
4. 在侧边栏和 AI 对话，AI 根据对话实时增删改节点。
5. 所有节点都能手动改、拖、删、重排，AI 生成的内容不是只读的。
6. 导出为 PNG、SVG、Markdown、OPML，能被 XMind、Obsidian 接住。
7. 登录后在任何设备打开，导图都在；未登录也能先试用，登录后迁移。
8. 在设置里切换 AI 模型：用平台内置的，或填自己的 Claude / OpenAI / 任意兼容接口的 Key，或连本地 Ollama。

## 4. AI 交互的三种模式

三种模式是同一套底层能力（AI 输出"树操作"）的不同入口，不是三套系统。

| 模式       | 入口                  | 适用                             |
| ---------- | --------------------- | -------------------------------- |
| 一次性生成 | 空画布的输入框        | 冷启动，快速得到骨架             |
| 节点级生长 | 节点右键菜单 / 快捷键 | 主流程，逐枝深入                 |
| 对话式     | 侧边栏聊天面板        | 复杂意图，"把第二层按时间线重排" |

**共同原则**：AI 只提交操作，用户随时可撤销；流式呈现，节点逐个出现；AI 看到的上下文是根到当前节点的路径加兄弟节点，不是整棵树。

## 5. 功能范围

### v1 做

- 画布：无限画布、缩放平移、自动树形布局、拖拽重排、多选、右键菜单、快捷键
- 节点：标题、备注、颜色标记、折叠展开
- AI：上述三种模式、文本导入
- 模型：内置 Claude 与 OpenAI 兼容接口，支持用户自填 Key 和 base URL，支持本地开源模型（Ollama 等）
- 账号：邮箱 / GitHub / Google 登录
- 存储：云端保存、自动保存、版本历史（最近 N 次）
- 导出：PNG、SVG、Markdown、OPML
- 用量：每用户每日 AI 调用配额，防止 Key 被刷

### v1 不做

- 多人实时协作
- 移动端原生 App（响应式网页可看，不保证可编辑）
- 模板市场、社区分享
- 导入 XMind / FreeMind 文件（v2 考虑）

## 6. 非功能需求

- 首屏可交互 < 2s，AI 首个节点出现 < 3s
- 一张 500 节点的导图拖拽不掉帧
- API Key 只在服务端出现，前端永远拿不到
- 每个 AI 请求有超时、重试和用户可见的错误提示
- 用户数据按行级权限隔离，任何用户只能读写自己的导图

## 7. 成功指标（v1 上线后）

- 新用户首次生成导图的完成率
- 人均"节点级生长"调用次数（衡量核心差异化是否被用）
- 7 日留存
- AI 生成内容被手动修改的比例（太高说明质量差，太低说明用户没在用）

## 8. 里程碑

| 阶段                 | 目标                                                  | 验收                             |
| -------------------- | ----------------------------------------------------- | -------------------------------- |
| M1 画布              | 手动建树、拖拽、布局、本地保存全部跑通                | 不接 AI 也能当一个普通导图工具用 |
| M2 账号与云存储      | 登录、云端保存、多端打开                              | 换设备能看到同一张图             |
| M3 主题生成          | 输入主题流式长出骨架，Claude 和 OpenAI 兼容接口都能跑 | 三层导图 10 秒内完成             |
| M3.5 开源模型        | 本地 Ollama 可用，用户可自填提供方                    | 切换模型后同一功能都正常         |
| M4 节点生长          | 四种节点动作                                          | 任意节点可深入                   |
| M5 文本导入 + 对话式 | 粘贴提炼、侧边栏对话改图                              | 三种模式齐全                     |
| M6 导出与打磨        | 四种导出、快捷键、undo/redo、空状态引导               | 可对外发布                       |

## 9. 开放问题

- 免费配额设多少，是否需要付费层
- 中英文 Prompt 分别调还是统一
- 版本历史保留多少次、多久
